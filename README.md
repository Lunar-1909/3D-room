# 3D-room

Web 3D phong cach vu tru + gaming duoc dung tu ban ve phong 2D.

## Chay local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Dieu khien

- `W`, `A`, `S`, `D` hoac phim mui ten de di chuyen.
- Keo chuot de xoay goc nhin.
- Cuon chuot de phong to/thu nho.
- Re chuot vao noi that de xem ten, gia tien va cong dung.
- Click cua, rem, may lanh, may giat, tu quan ao, hoc cau thang... de xem animation.
